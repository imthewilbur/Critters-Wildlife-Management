# Critter's Wildlife Management

Website for Critter's Wildlife Management, LLC: family-owned bat and wildlife removal serving Lincoln, Omaha and surrounding areas since 2010.

Static site served by GitHub Pages from the `main` branch root. Same design system as Star City Beetles, Bones & Oddities (sister business).

## Updating

- **Phone, email, service area, hours, prices:** edit the `SITE` block near the bottom of `index.html`. Set a price to a number (e.g. `150`) to show "$150 / starting at"; leave it `null` to show "Call For / A quote".
- **Job photos:** `images/job-1.jpg` … `images/job-7.jpg` fill the Field Log; `job-4.jpg` is also the hero background and `job-6`, `job-7` and `attic.jpg` sit behind the bat section. Swap a photo by replacing the file with the same name (resize to ~1600px on the long side first), then update its `alt` and caption in the Field Log section.
- **Logo:** `images/logo.png` is the round badge in the nav. The bat emblem used across the page lives in the `<symbol id="bat">` block at the top of `index.html`.
- **Share image:** `images/og.jpg` (1200×630) for Facebook/text link previews.
- **Favicon:** `images/favicon.png`.
